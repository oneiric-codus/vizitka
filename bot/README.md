# Бот заявок: настройка за 15 минут

Бот работает бесплатно на Cloudflare Workers (до 100 000 запросов в день). Токен бота хранится там, а не в коде сайта.

Что получится:
- заявка с формы на сайте приходит вам в Telegram;
- клиент может написать боту сам: выбирает услугу кнопкой и описывает задачу, бот пересылает это вам;
- чтобы ответить клиенту, нажмите «Ответить» на его заявке в боте и напишите текст. Бот передаст его клиенту.

## 1. Создайте бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Имя: например, `Степан Семенюк | Заявки`.
3. Ник: должен заканчиваться на `bot`, например `stepan_zayavki_bot`.
4. BotFather пришлёт токен вида `1234567890:AA...`. Это пароль от бота: никому его не отправляйте, вставите только в Cloudflare.

## 2. Создайте Worker

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно).
2. **Workers & Pages → Create → Create Worker**. Назовите, например, `stepan-bot`, нажмите **Deploy**.
3. Нажмите **Edit code**, удалите всё и вставьте содержимое файла `worker.js`. Нажмите **Deploy**.

## 3. Добавьте токен

В Worker откройте **Settings → Variables and Secrets → Add**:
тип **Secret**, имя `BOT_TOKEN`, значение — токен от BotFather. Нажмите **Deploy**.

## 4. Подключите бота

Откройте в браузере адрес Worker с `/setup` на конце, например:

```
https://stepan-bot.ВАШ-АККАУНТ.workers.dev/setup
```

Должно появиться «✓ Бот подключён» и адрес для формы.

## 5. Скажите боту, куда слать заявки

1. Напишите своему боту `/id`. Он ответит числом, это ваш chat_id.
2. Добавьте в Worker переменную `ADMIN_CHAT_ID` (тип Text) с этим числом и нажмите **Deploy**.

## 6. Подключите форму на сайте

В `index.html`, в блоке «НАСТРОЙКИ»:

```js
const LEAD_ENDPOINT = "https://stepan-bot.ВАШ-АККАУНТ.workers.dev/lead";
```

и в `CONTACTS` укажите `bot: "ник_вашего_бота"`, тогда в контактах и подвале появится кнопка бота.

## Проверка

- Заполните форму на сайте: заявка придёт в бота за пару секунд.
- Попросите друга написать боту `/start`: у него появятся кнопки услуг, а у вас заявка.
- Если форма не смогла отправить заявку (например, Worker выключен), сайт сам покажет текст заявки, чтобы клиент скопировал его и отправил вам вручную. Заявки не теряются.
