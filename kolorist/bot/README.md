# Бот записи на курс «Колорист с нуля»

Работает бесплатно на Cloudflare Workers, как бот заявок Степана. Токен бота хранится в Cloudflare, а не на сайте.

Что умеет:
- кнопки «Записаться», «Программа», «Стоимость», «Частые вопросы»;
- запись в один тап: ученица нажимает «Отправить номер», и заявка с именем, телефоном и ссылкой на её Telegram приходит Юлии;
- заявки со страницы курса (чат-виджет внизу страницы) тоже приходят в этот бот;
- любой другой вопрос пересылается Юлии. Чтобы ответить, нажмите «Ответить» на заявке и напишите текст, бот передаст его ученице;
- заявки можно слать сразу нескольким людям (например, Юлии и Степану).

Данные курса (дата, цена, адрес, программа) меняются в начале `worker.js`, в блоке «данные курса».

## 1. Создайте бота

1. [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя: `Юлия · Колорист с нуля`.
3. Ник на `bot`, например `kolorist_ufa_bot`.
4. Скопируйте токен. Никому его не отправляйте, он вставляется только в Cloudflare.
5. Там же можно поставить аватарку: `/setuserpic` (подойдёт роза из `../img/rose.webp` или фото Юлии).

## 2. Создайте Worker

[dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Create Worker** → имя `kolorist-bot` → **Deploy** → **Edit code** → вставьте весь `worker.js` → **Deploy**.

## 3. Секрет и подключение

1. **Settings → Variables and Secrets → Add**: тип **Secret**, имя `BOT_TOKEN`, значение — токен. **Deploy**.
2. Откройте `https://kolorist-bot.ВАШ-АККАУНТ.workers.dev/setup` — должно появиться «✓ Бот подключён».

## 4. Куда слать заявки

1. Напишите боту `/id` — он ответит числом (chat_id).
2. Добавьте переменную `ADMIN_CHAT_ID` (тип Text). Несколько получателей — через запятую: `111111111,222222222`. **Deploy**.

Пока Юлия не подключилась, поставьте свой chat_id, а потом попросите её написать боту `/id` и добавьте её число.

## 5. Подключите страницу

В `kolorist/index.html` найдите блок `НАСТРОЙКИ` и впишите:

```js
var LEAD_ENDPOINT='https://kolorist-bot.ВАШ-АККАУНТ.workers.dev/lead';
var BOT_USERNAME='kolorist_ufa_bot';
```

Пока `LEAD_ENDPOINT` пустой, виджет на странице работает в демо-режиме: показывает «Заявка у Юлии», но никуда не отправляет.
Если Worker недоступен, виджет предложит написать Юлии напрямую в Telegram — заявки не теряются.
