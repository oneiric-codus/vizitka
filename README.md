# Степан Семенюк — портфолио

Одностраничный сайт: сайты, веб-дизайн, Telegram-боты и визитки под любую нишу.

- `index.html` — весь сайт в одном файле. Проекты, контакты и адрес бота меняются в блоке «НАСТРОЙКИ» в начале скрипта.
- `bot/` — бот заявок на Cloudflare Workers и инструкция по настройке (`bot/README.md`).

Сайт: https://oneiric-codus.github.io/vizitka/
